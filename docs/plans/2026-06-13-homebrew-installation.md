# Homebrew Installation Implementation Plan

> **For agentic workers:** Use executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship wtr through Homebrew by auto-generating and pushing `Formula/wtr.rb` to the shared `abogoyavlensky/homebrew-tap` on every release.

**Tech Stack:** GitHub Actions, Bash, Homebrew (Ruby formula)

---

## Design

The wtr repo owns the formula *generator*; release CI regenerates and pushes
`Formula/wtr.rb` into the shared `abogoyavlensky/homebrew-tap` on every `v*`
tag. This mirrors the lgx setup.

Flow:

```
git push tag v0.1.0
  └─ release.yml
       checks ─→ release (builds wtr_<ver>_<target>.tar.gz + checksums.txt, GH release)
                   └─ homebrew (new job)
                        ├─ gh release download checksums.txt
                        ├─ git clone homebrew-tap   (HOMEBREW_TAP_TOKEN)
                        ├─ scripts/generate-formula.sh <ver> checksums.txt > tap/Formula/wtr.rb
                        └─ commit "wtr <ver>" & push  (skip if unchanged)
```

**Key simplification vs lgx:** the wtr binary is self-contained (it is built
with `lgx build -bundle-base`, and release CI smoke-tests `./wtr list`
directly). So the wtr formula has **no `caveats` block and no `let-go`
dependency** — just `bin.install "wtr"` and a `wtr --version` test. This is
the main difference from `lgx.rb`, which carries a let-go caveat.

**Error handling:** `generate-formula.sh` fails fast if a target checksum is
missing (`set -euo pipefail` + an explicit error in the `sha_for` helper). The
homebrew job exits cleanly without committing when the formula is unchanged
(`git diff --cached --quiet`).

**Testing strategy:** generator output is verified locally (generate against a
sample `checksums.txt` and eyeball the Ruby; `bash -n` syntax check).
End-to-end push to the tap is exercised by the next real `v*` release, the only
context where the tap token and real release checksums exist.

### Prerequisite (ops, outside this code)

The wtr GitHub repo needs the **`HOMEBREW_TAP_TOKEN`** secret — a PAT with
push access to `abogoyavlensky/homebrew-tap`, the same secret lgx uses. Confirm
it is set on the wtr repo, or the homebrew job will fail to push.

## File Structure

- `scripts/generate-formula.sh` (new) — prints `wtr.rb` for a given version +
  checksums file. Adapted from lgx's script: class `Wtr`, wtr URLs/artifact
  names, `bin.install "wtr"`, no caveats, `wtr --version` test.
- `.github/workflows/release.yml` (modify) — add a `homebrew` job
  `needs: [release]` that generates and pushes the formula.
- `README.md` (modify) — add a "With Homebrew" subsection under Installation.
- `../homebrew-tap/README.md` (modify, separate repo) — add a `wtr` section
  mirroring the lgx entry, without the let-go requirement note.

## Implementation Steps

### Task 1: Add the formula generator script

**Files:**
- Create: `scripts/generate-formula.sh`

- [ ] **Step 1: Write the script**
  Adapt `../lgx/scripts/generate-formula.sh`. Keep the structure: `set -euo
  pipefail`, an `err` helper, argument check (`VERSION CHECKSUMS_FILE`), and a
  `sha_for <target>` helper that `awk`-extracts the sha for
  `wtr_${version}_${target}.tar.gz` and fails if missing. Resolve all four
  targets (`darwin_amd64`, `darwin_arm64`, `linux_amd64`, `linux_arm64`).
  Emit a heredoc producing the formula with these wtr-specific values:
  - Header comment: generated by `scripts/generate-formula.sh` in the wtr repo, DO NOT EDIT.
  - `class Wtr < Formula`
  - `desc "Git worktree router for managing multiple worktrees"`
  - `homepage "https://github.com/abogoyavlensky/wtr"`
  - `license "MIT"`
  - `livecheck do skip "Formula is updated by wtr release CI" end`
  - `on_macos`/`on_linux` × `on_intel`/`on_arm` blocks with
    `https://github.com/abogoyavlensky/wtr/releases/download/v${version}/wtr_${version}_<target>.tar.gz`
    and the matching `sha256`.
  - `def install; bin.install "wtr"; end`
  - **No `caveats` block.**
  - `test do assert_match version.to_s, shell_output("#{bin}/wtr --version") end`
  - Make it executable (`chmod +x`).

- [ ] **Step 2: Syntax check**
  Run: `bash -n scripts/generate-formula.sh`
  Expected: no output, exit 0.

- [ ] **Step 3: Generate against a sample checksums file**
  Create a throwaway checksums file with the four `wtr_0.1.0_<target>.tar.gz`
  entries (any 64-hex shas), then run:
  `scripts/generate-formula.sh 0.1.0 /tmp/wtr-checksums.txt`
  Expected: a complete `wtr.rb` on stdout — class `Wtr`, four url/sha256 pairs,
  `bin.install "wtr"`, a `wtr --version` test, and **no caveats block**.

- [ ] **Step 4: Verify the missing-checksum failure path**
  Run the generator against a checksums file missing one target.
  Expected: non-zero exit with an explicit "no checksum for ..." error.

### Task 2: Add the homebrew release job

**Files:**
- Modify: `.github/workflows/release.yml`

- [ ] **Step 1: Add the `homebrew` job**
  After the `release` job, add a `homebrew` job with `needs: [release]`,
  `runs-on: ubuntu-latest`, mirroring `../lgx/.github/workflows/release.yml`'s
  homebrew job but with wtr specifics:
  - `actions/checkout@v6` (consistent with wtr's other jobs).
  - env: `GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}`,
    `TAP_TOKEN: ${{ secrets.HOMEBREW_TAP_TOKEN }}`,
    `TAG: ${{ github.ref_name }}`.
  - Steps: `version="${TAG#v}"`; `gh release download "$TAG" --repo
    "$GITHUB_REPOSITORY" -p checksums.txt -O checksums.txt`; clone the tap with
    `https://x-access-token:${TAP_TOKEN}@github.com/abogoyavlensky/homebrew-tap.git tap`;
    `mkdir -p tap/Formula`; `bash scripts/generate-formula.sh "$version"
    checksums.txt > tap/Formula/wtr.rb`; configure `github-actions[bot]` git
    user; `git add Formula/wtr.rb`; skip on no change
    (`git diff --cached --quiet && { echo "formula unchanged"; exit 0; }`);
    `git commit -m "wtr ${version}"`; `git push`.

- [ ] **Step 2: Validate workflow YAML**
  Run: `python3 -c "import yaml,sys; yaml.safe_load(open('.github/workflows/release.yml'))"`
  Expected: no output, exit 0 (YAML parses).
